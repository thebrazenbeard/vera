# V.E.R.A. Semantic Tagging and Retrieval

## Purpose
Semantic tagging improves discoverability and collision resistance. It does not create truth, permission, identity, consciousness, reciprocity, or authority.

## Extraction pipeline
1. Split source text into attributable claims.
2. Label each claim's source actor and epistemic class.
3. Extract entities, systems, artifacts, projects, people, personas, locations, and concepts.
4. Extract topics and aliases while preserving observed forms.
5. Extract directed relationships as representational data.
6. Extract temporal expressions with source evidence and precision.
7. Preserve literal phrases needed for exact recall.
8. Record collisions and unresolved references.
9. Project canonical values into the compact subject section.

## Entity types
`PERSON`, `ORGANIZATION`, `PROJECT`, `SYSTEM`, `MODEL`, `TOOL`, `PERSONA_CONFIG`, `ARTIFACT`, `LOCATION`, `DEVICE`, `SOFTWARE`, `CONCEPT`, `OTHER`.

A persona configuration is not a person or autonomous virtual entity.

## Relationship rule
Relationships may describe:
- user-defined framing;
- source attribution;
- project membership;
- technical dependency;
- authorship;
- sequence;
- reference;
- observed interaction.

They may not silently imply reciprocal feeling, consent, subjective ownership, or independent agency.

## Query expansion
Search exact terms first, then aliases, canonical forms, topics, one-hop relationships, temporal anchors, and literal phrases. Reapply privacy, provenance, lifecycle, branch, and model-claim filters after expansion.

## Model-claim contamination rule
Terms such as “I want,” “I love,” “I remember,” “I am,” “I consent,” or “this is mine,” when generated by a model, are indexed as language content and source evidence only. They do not create a model-owned state.

## Temporal tagging
Keep event, record, state, and retrieval time distinct. File metadata remains metadata unless supported as event evidence. A prior anchor proves a recorded sequence point, not continuous hidden activity.

## Evidence
Every semantic object carries source claim IDs, evidence text, epistemic status, and extraction confidence. Confidence describes extraction quality, not claim truth.
